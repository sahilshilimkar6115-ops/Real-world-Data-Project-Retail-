# Real-World Data Project – Retail Sales Analysis

## 📌 Project Title
Retail Sales Data Analysis using Python

---

## 📖 Project Description
This project is based on a real-world retail sales dataset.  
The main objective of this project is to analyze sales performance, identify revenue trends, and generate useful business insights using Data Science techniques.

The project demonstrates:
- Data collection
- Data cleaning
- Data analysis
- Data visualization
- Business insights generation

This project helps understand how companies use data analysis to improve decision-making in the retail industry.

---

# 🎯 Objectives
- Analyze product-wise sales performance
- Identify the highest revenue-generating products
- Compare sales across different regions
- Visualize business insights using charts and graphs
- Apply Python Data Science concepts to real-world data

# 🔍 Steps Performed

## 1. Data Collection
A retail sales dataset was created containing product sales information from multiple regions.

## 2. Data Cleaning
- Removed missing values
- Checked data consistency
- Formatted date columns properly

## 3. Exploratory Data Analysis (EDA)
Performed analysis to identify:
- Product-wise revenue
- Region-wise revenue
- Sales trends

## 4. Data Visualization
Created charts using Matplotlib:
- Bar chart for revenue by product
- Pie chart for revenue share by region

## 5. Business Insights
- Laptops generated the highest revenue
- Major sales came from metropolitan regions
- Product demand varies by region
